# US-9.6 — Avvio manuale del controllo di una fonte

**Epic:** [EPIC 9 — Monitoraggio automatico delle fonti (solo Admin)](../epics/epic-9-monitoraggio-automatico.md)

**Attore:** Admin

**Necessità:** Voglio avviare subito il controllo di una fonte

**Obiettivo:** Per verificare un aggiornamento che mi è stato segnalato senza aspettare il controllo programmato.

## Criteri di accettazione

- Dalla pagina di monitoraggio o dalla scheda della fonte l'Admin può avviare il controllo.
- Il controllo manuale segue le stesse regole di quello automatico (US-9.3).
- L'Admin vede l'esito appena il controllo è terminato.
- Il controllo manuale non modifica la pianificazione dei controlli automatici.
