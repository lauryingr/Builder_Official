# US-5.4 — Download del documento in PDF

**Epic:** [EPIC 5 — Archivio normativo](../epics/epic-5-archivio-normativo.md)

**Attore:** Utente autenticato

**Necessità:** Voglio scaricare il documento in PDF

**Obiettivo:** Per consultarlo offline e allegarlo alla documentazione di progetto.

## Criteri di accettazione

- Dalla scheda, dai risultati di ricerca e dalle cartelle l'utente può scaricare il PDF.
- Il file scaricato è la versione in vigore e ha un nome che contiene comune, tipologia e data/versione.
- Se il file non è disponibile viene mostrato un messaggio chiaro e l'utente può fare una segnalazione (US-7.1).
